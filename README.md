# 太原供水设施台账

Vue 3.5 / Element Plus / Vite。保留表井、水表间、消防栓、阀门井、表卡和小区资料入口。

## 本地重建版

将 `tygs` 和 `tygs-java` 克隆到同一父目录。在 `tygs-java` 中运行 `mvn package`，在本目录运行 `pnpm install --frozen-lockfile`。需要 Java 17+，工作簿校验脚本需要支持 TypeScript 类型擦除的 Node.js。启动脚本优先使用 `JAVA_HOME`，未设置时使用 PATH 中的 `java`。

```sh
node scripts/local-tygs.mjs start
node scripts/local-tygs.mjs status
node scripts/verify-ledgers.mjs
```

访问 <http://127.0.0.1:5197/home/ledger>。账号和随机生成的密码位于 `../local-tygs-data/credentials.json`，仅本机用户可读。服务只监听回环地址，不对外发布。登录后可查阅五类台账、原始字段、来源工作表和行号、照片链接、跨表候选及文件 SHA-256。

本地数据使用 H2 文件库；不是历史 MySQL 数据库的完整恢复。旧业务表结构按当前 Java 实体重建，只导入五个工作簿支持的内容。表卡、账号历史、维修日志等未提供的数据不会补造。默认生产 MySQL 配置不变。

## 页面与查询性能

本地启动默认先构建，再通过 Vite preview 提供压缩后的静态资源，构建产物保存在各实例数据目录的 `frontend-build`，不共用测试实例文件。需要热更新时，先停止实例，再使用 `LOCAL_FRONTEND_MODE=dev node scripts/local-tygs.mjs start`。preview 仅用于当前回环地址下的本地使用，不替代生产部署方案。

四类设施查询通过 `/facilities/{rooms|meters|hydrants|valves}/records` 按页读取，默认每页 30 条。筛选在服务端执行，翻页沿用已提交的筛选；新的搜索会取消旧请求，迟到响应不会覆盖当前结果。阀门井导出按每批 500 条读取全部筛选结果，遇到总数变化或重复行时报错；它不是并发编辑下的数据库快照。Excel 库仅在导入或导出时加载，地图统计和列表并发请求。

## 导入与核验

“采集台账 → 导入工作簿”支持五类表头识别、预览和分批导入。全空行跳过，其余行保留原工作表名称、物理行号、单元格值/类型/格式/公式/超链接和未映射字段。文本编号保持文本；源文件本身已丢失的信息无法恢复。重复表头、错误单元格及缺少计算缓存的公式会报错，不静默导入。

同一文件 SHA-256、工作表和行号只写入一次；重试可跳过已保存的行。不同文件即使业务编号相同，也不会自动去重或合并。导入采用每批事务；中途失败时已完成批次保留，同一原文件可重试。文件内容变化后视为新来源版本，需先核对，避免把修订版误认为增量数据。

```sh
node scripts/import-ledgers.mjs
node scripts/verify-ledgers.mjs
node scripts/audit-ledger-links.mjs
```

批量脚本的五个原件路径见 `scripts/import-ledgers.mjs`；只读取原件并校验本地副本，复跑不增加同源记录。全量校验将本地原件副本重新解析，与数据库逐行比较，并核对映射到旧业务表的每个字段。导入、校验和关联/照片审计结果在 `../local-tygs-data/` 中；该目录含敏感业务数据和凭据，不应提交 Git。

2026-10-12 重建结果：水表间 13,673 行、总表 3,399 行、井室 7,008 行、复核总表 467 行、阀门维护检修 1,965 行，共 26,512 条来源记录。这不是去重后的设施数。业务表分别保存水表间 13,673 条、表井 3,399 条、阀门井 5,356 条、消防栓 1,404 条。复核/维护 2,432 条保持未关联；另有 248 条混合或不明确的井室类型待核实，原记录全部保留。

## 补全的业务模块

三供一业、户表信息、供水附属设施登记卡、户表户管、户表总管、维护总管支持按字段查询、分页、新增、编辑、Excel 导入导出、查看来源与修改记录。管理员可归档和恢复记录，归档不删除原内容。编辑带版本校验，遇到他人修改需重新打开核对。消防栓、水表间、阀门井的新增页面已接入保存，返回原设施查询页可查看新记录；新增户表对应独立的户表信息库。

五份采集台账不包含足以确认三供一业或小区管理类别的数据，因此这些模块初始为空，需录入或导入相应资料，不自动从设施名称猜测分类。没有添加演示业务数据。新增模块当前依赖后端 `local` profile 的 `/workspace/*` 接口，尚未适配生产 MySQL。

业务模块导入每批最多 100 条，保留来源哈希、工作表、行号、原始字段与单元格。表卡导入需选择“横向表格”或“打印表卡”；打印版以每个“设施名称”开始一条记录，缺字段或重复字段会报错，不从下一张卡借值。同源重试不会覆盖后续人工编辑；修订文件仍视为新来源，不按业务编号合并。导出为当前筛选下的业务字段，不替代含来源与审计数据的完整数据库备份。

设施地图读取表井、水表间、阀门井和消防栓的实际记录。人工经纬度单独保存，并要求注明 WGS84 或 GCJ-02 坐标系及定位依据；WGS84 在显示时转换为高德底图使用的 GCJ-02，保存值不改写。地图只显示本页点位，人工录入点为蓝色，地址参考点为橙色。原始地址/位置字段保持不变。

地址试定位由管理员逐条触发，打开核对窗口不会发送地址。查询仅将地址与限定城市“太原市”交给高德，不发送户号、姓名、电话或照片链接；带网址、邮箱、手机号等异常文本的地址会被阻止。当前没有批量查询或自动重试。返回唯一的门牌级结果，且城市、明确区县、道路及门牌号与原地址一致时，保存为“地址参考点”；道路、小区、多个候选、地址冲突或服务失败均保留待核实，不绘制候选坐标。地址参考点不代表设施实测位置。人工坐标优先，源地址变化后旧地址匹配不再上图。结果与判断依据追加保存，重试保存只访问本地服务。

高德 JS Key 通过私有 `.env.local` 的 `VITE_AMAP_KEY` 配置，本地地址查询另要求配套 `VITE_AMAP_SECURITY_CODE`，要求见[高德加载说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/load)。配置变化需重启前端并刷新页面。2026-10-12 经授权仅试查两条地址，两条均在 SDK 回调层超时；第二条网络响应确认 `INVALID_USER_SCODE`（10008），本地缺少安全密钥。未发送第三条，未写入任何真实地址参考坐标。查询记录中的超时保留原样，不改写成成功；网络诊断回执保存在本地私有数据目录。缺项补齐前禁用新查询。底图属于在线服务；服务不可用时，设施列表及坐标录入仍可使用。浏览器端配置可被用户查看，应在服务商后台限制授权域名，不在源码或日志中公开凭据。

设施查询表的地址/名称列使用可伸缩宽度，页面与新增表单随可用区域铺满。窄屏保留表格内部横向滚动，不压缩原字段或隐藏数据。

## 关联和照片边界

跨表统计为精确字段匹配生成的候选，未写入任何已确认关系。各规则结果可能重叠，不能相加。地址/位置同时命中同一目标行只计一个候选；不同来源的两行仍计两个候选。总表与水表间的同名只代表可能的场所关系，不能据此认定是同一设施。编号重用、空键和街道/户号冲突需人工核查。

照片字段含 52,987 次链接、44,709 个不同 URL，均为企业微信微盘分享页面，没有直接图片 URL。抽查 29 个不同链接均返回未登录页面且没有下载地址；真实浏览器样本显示“文件已设置权限，请登录后查看”。这不代表已检查全部链接。界面保留打开原分享页的入口；在取得授权账号访问或实际图片文件前，不能在本地展示这些原图。四组跨表检查没有完全相同的照片 URL，不能据此判断图片内容不同。

## 停止、备份与恢复

```sh
node scripts/local-tygs.mjs stop
node scripts/local-tygs.mjs backup
node scripts/local-tygs.mjs start
```

停止不会删除数据。备份要求服务已停止，将 `facilities.mv.db` 和配套凭据复制到带时间戳的私有快照目录，核对 SHA-256，再用第二份数据库副本实际打开查询。回执写入快照内 `receipt.json`。工作簿副本和校验记录继续保留在 `local-tygs-data`，完整迁移时需一起保存。

恢复时先停止服务并保留现有数据；将快照的数据库文件与配套凭据一起恢复到 `local-tygs-data`，不要覆盖正在使用的数据库。要重建空库，应保留整个原目录并另建数据目录，再运行启动与导入流程；不要删除唯一副本。

## 开发与生产配置

`pnpm type-check`、`pnpm test`、`pnpm lint`、`pnpm build` 用于验证。本地启动脚本设置 `VITE_API_BASE=/api`、`VITE_API_PROXY=http://127.0.0.1:8097` 和 `VITE_LOCAL_LEDGER=1`。未启用最后一个开关时不提供本地专用采集台账入口；原生产部署仍需真实 MySQL 配置和独立验证。

启动脚本支持 `LOCAL_RUN_DATA_DIR`、`LOCAL_BACKEND_PORT`、`LOCAL_FRONTEND_PORT`，可用不同目录和端口建立隔离测试实例，启动、停止、状态和备份时需使用同一组配置。跨域白名单只包含该实例的回环前端地址，不开放任意来源。本次页面测试实例使用 `local-tygs-qa-20261012` 和 8098/5198，模拟记录与正式本地库完全分离。

登录会话有效期 8 小时，退出后撤销。前端不保存密码或私钥。公开注册已关闭，账号由管理员配置。旧私钥已从当前代码移除，历史暴露的服务器证书仍需重新签发并撤销。
